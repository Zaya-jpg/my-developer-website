What I Learned Building My First Website

Building my first website was both exciting and challenging. I wanted to create something simple, yet functional to practice what I'd been learning about HTML, CSS, and JavaScript. Here's what I learned from the experience:

I began by sketching out the layout and deciding on the sections I wanted: a homepage, an about section, and a feedback form. I used basic HTML for structure and CSS for styling. Planning the layout first made the rest of the process smoother.

I learned how to use semantic HTML elements like header, section, and footer elements, which helped organize the content. With CSS, I practiced using flexbox and media queries to make the site responsive. I also realized how small design choices affect user experience.

My Favorite CSS Trick So Far- The :hover Effect

One of the things I love most about learning CSS is how small changes can make a website feel more interactive. So far, my favorite CSS trick is the :hover pseudo-class.

It's so simple but it instantly makes buttons and links feel alive. I used it in my hotel feedback form to make submit buttons change color when the user hovers around it. The tiny effect makes a big difference in user experience. I'm starting to explore more psuedo-classes and transitions now to make things even smoother!
